# 森夜 · 極簡數位底牌

線上網址：https://lrsjudge.netlify.app/

本地執行 `npm ci`、`npm start`，開啟 http://localhost:3000 。需要 Node.js 20+（Netlify 使用 Node.js 22）。

## 操作流程

1. 法官選擇 **6～12 人**中的任意人數，自訂狼人、村民、預言家、女巫、獵人和守衛的數量，建立房間取得 **4 位數**房間碼。各角色可配置多位；總數必須等於遊戲人數，且至少包含一位狼人和一位好人。切換人數會載入推薦配置，也可一鍵恢復推薦。法官不佔座位。
2. 玩家輸入房號，自選實體座位，必須輸入 1～20 字名字才能入座；不需帳號。名字會顯示在大廳與主持人座位格，重連及重發保留名字。
3. 最後一個座位入座時，伺服器依主持人儲存的配置隨機派牌；重新發牌亦保留同一配置。房間顯示實際的狼人／神職／平民數量。
4. 玩家頁顯示名字、存活狀態、警徽及投票看板；「查看我的底牌」開啟黑底全螢幕，持續按住底牌 350 毫秒顯示角色與一句技能提示。鬆手、滑出、觸控取消、切換頁面或視窗失焦立即遮蔽。亦支援持續按住空白鍵或 Enter。
5. 玩家長按查看底牌後即可參與線下遊戲，無須確認回執。法官可在座位格查看每位玩家的角色身分，僅主持人憑證可取得全場底牌；一般玩家與公開入座頁看不到他人身分。法官可推進／回退階段、指定警長、暫存夜間目標、發起投票，以及手動出局／恢復。重新發牌保留名字和座位，重設階段、警徽、存活與投票並重新分配身分。

## 主持與投票規則

- 依序進行 13 階段：第 1 晚 → 警長競選 → 第 1 天 → 第 2 晚／天，直至第 6 晚／天。階段切換有確認；投票中須先結束投票。回退保留已公布的存活和警徽狀態，需另行手動修正。
- 夜間目標只提供給主持人。清空目標代表平安夜；按「公布夜間結算」或從夜晚推進下一階段才套用出局。已公布的同一晚不會因回退而重複生效。神職技能由法官在線下確認後調整目標或手動狀態。
- 警長競選採線下競選，主持人授予／收回警徽。此版警徽僅標記，一人一票，允許投自己或棄權。
- 白天由法官開放投票。存活玩家選擇後二次確認，提交不可更改；伺服器按輪次與投票 ID 驗證並原子保存。出局玩家只能觀戰，不能投票或被選為目標。
- 法官可即時查看已投／未投及票數；其他玩家只能看自己的選擇，結束後才看到票數。可提前結束，未投者不計票。唯一最高票需法官再次確認才淘汰；平票或全棄權／無票不淘汰，可重投或手動處理。
- 手動出局與恢復均二次確認；若投票進行中更改存活，本輪作廢，需重新發起。主持人操作帶版本與局數，避免舊畫面覆蓋新狀態；伺服器保留最近 80 條主持紀錄。
- 勝負與特殊技能的具體規則仍由法官裁定，沒有自動勝負判定。

## 手機與重連

線上版本直接開啟 https://lrsjudge.netlify.app/，手機可以使用不同網路。

本地版本需手機與電腦連同一 Wi-Fi，開啟 `http://電腦區域網路IP:3000`；防火牆需允許 TCP 3000。

座位憑證保存在同一瀏覽器的 LocalStorage，關閉後重開會自動恢復；也可重新輸入房號恢復。恢復不會重派或重複佔位。其他装置不能僅憑房號及座位冒領底牌。清除瀏覽資料或更換瀏覽器後，無法恢復原憑證，需由法官解散重建。

每 2 秒同步座位、階段、存活、票數與重新發牌；頁面隱藏時暫停，返回時立即同步。短暫斷線仍可查看已收到的牌，重新連線後更新。關閉瀏覽器後的恢復需要伺服器可連線。

線上版本使用 Netlify Functions 與 Netlify Blobs：房間在不同請求與重新部署之間保留，最後一次入座或重發後 24 小時過期。過期資料在讀取時失效，同一房號可被新房間重新使用。座位與派牌採強一致性讀取及版本條件寫入，避免並發選座覆蓋。解散使用版本化標記，避免已發出的請求重新建立房間。

本地 `npm start` 使用記憶體儲存，重啟仍會清除房間。應用面向可信任的線下聚會，尚未實作反濫用限流。

## Netlify 部署

GitHub 的 `main` 分支已連接 `lrsjudge` 站點。`netlify.toml` 設定發布 `public/`、打包 `netlify/functions/api.mjs`，並在構建時執行測試。API 路徑為 `/api/*`。Blobs 憑證由 Netlify 自動配置，不需在程式碼保存金鑰。

推送 `main` 即觸發部署。可執行 `npx netlify-cli build --offline` 驗證構建與函式打包。

## 驗證

`npm test`：涵蓋 6～12 人預設及自訂配置、無效配置驗證、舊房間相容、座位競爭、自動派牌、身分隔離、憑證恢復、法官權限、重發及解散，以及長按卡片的遮蔽事件。另驗證多個函式實例同時入座、過期房間和解散後的版本衝突。

新增流程測試涵蓋全部 13 階段、權限、並發階段操作、夜間保密與單次结算、棄權和平票、不可改票、出局禁投、投票作廢、斷線恢復與重新發牌重設。

## 擴充角色

可自訂白痴、騎士、狼王、白狼王、魔術師、攝夢人、石像鬼、守墓人、機械狼人數。狼王、白狼王、石像鬼、機械狼計入狼人陣營；其餘新增角色計入神職。推薦配置保持原有板子，擴充角色預設為 0。底牌附有簡短提示，特殊技能仍由法官依本局桌規執行，未自動化技能結算。

另新增狼美人、夢魘、血月使徒（狼人陣營）、獵魔人、通靈師（神職），目前共 20 種角色；支援人數配置、派牌、重發及底牌提示，特殊技能依桌規由法官處理。

平票重投规则：最高票并列者在同一阶段下一次重投中禁投，但仍可被投。连续平票按最新最高票名单禁投，不累积；切换阶段或重发重置。投票因状态修改作废后重开保留禁投名单。
